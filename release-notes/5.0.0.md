# YT Music Lite 5.0.0

- Replaces the embedded browser with a native Windows music interface.
- Adds Home, Search, Library, Queue, local playlists, audio import, and a native mini player.
- Bundles mpv, yt-dlp, and Deno for playback and search.
- Keeps verified in-app updates through Settings.

Windows CI validates compilation, local-audio playback, pause and process cleanup, navigation, queue behavior, playlists, Settings, and compact-window rendering.

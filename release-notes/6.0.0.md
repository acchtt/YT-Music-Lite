# YT Music Lite 6.0.0

YT Music Lite has been rebuilt as a lightweight native Windows music client.

## Highlights

- Native Home, Search, Library, Playlists, Queue, and Settings screens
- No continuously running WebView2 browser
- Native mini player, media keys, tray controls, and persistent queue
- On-demand YouTube catalog search and stream resolution
- Browser-cookie sign-in recovery through Edge, Chrome, Firefox, or cookies.txt
- Bounded artwork and playback memory
- SHA-256-verified in-app updates

## Verified Windows baseline

- 34.64 MiB idle
- 94.46 MiB peak while playing, including mpv
- 48.08 MiB after Stop

The release workflow rebuilds and validates these memory budgets before publishing the update.

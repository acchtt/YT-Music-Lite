# YT Music Lite 6.0.1

This maintenance release fixes the browser sign-in controls introduced in v6.0.0.

- Edge, Chrome, and Firefox now open a real Google/YouTube account chooser in a new browser window.
- Missing-browser and launch failures are shown clearly.
- The app explains how to complete sign-in and close the browser before playback.
- The low-memory native architecture remains unchanged.

Windows compilation, UI navigation, catalog search, playback cleanup, and enforced memory budgets passed before release.

# YT Music Lite 6.0.2

- Adds Brave to YouTube sign-in in Settings.
- Detects standard system-wide and per-user Brave installations.
- Opens the Google/YouTube account chooser in a new Brave window.
- Uses Brave cookies through the on-demand yt-dlp resolver.
- Adds automated coverage for Brave launch and authentication arguments.

The native client remains browser-free during normal use; Brave is opened only when the user starts sign-in.

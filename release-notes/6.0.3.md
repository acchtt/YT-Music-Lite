# YT Music Lite 6.0.3

This release completes Brave account recognition.

- Opens Brave with an isolated YT Music Lite authentication profile.
- Waits for the sign-in window to close before checking the session.
- Verifies authenticated Google/YouTube cookies before showing Connected.
- Rejects anonymous, incomplete, locked, and timed-out sessions with actionable errors.
- Deletes the temporary verification cookie file immediately.

Normal playback remains browser-free and low-memory.

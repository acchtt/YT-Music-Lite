# YT Music Lite 6.0.4

This release makes a connected account visible in the native client.

- Automatically syncs the authenticated YouTube Music Liked Music playlist after Brave sign-in.
- Imports up to 250 liked tracks into Library without duplicating local saves.
- Persists synced tracks and opens Library when sync completes.
- Adds a manual Sync action in Settings.
- Keeps account synchronization on demand so no browser or resolver remains active.

Windows compilation, UI parsing, playback cleanup, catalog search, and memory budgets passed before release.

# YT Music Lite 7.0.0

This release rebuilds the desktop client for Windows around Tauri 2, Svelte 5, Rust, WebView2, and a single persistent YouTube player.

- Replaces the React prototype and removes the second persistent mini-player WebView.
- Adds a polished Spotify-inspired Home, Search, Discover, Library, Playlist, Now Playing, and Settings shell.
- Uses a visible YouTube IFrame player and pauses playback when Windows minimizes the app.
- Adds queue controls, seeking, volume, lazy artwork, debounced search, and render containment for long lists.
- Adds SQLite listening events and a locally weighted Weekly Mix.
- Preserves account library synchronization and verified SHA-256 in-app updates.
- Adds an NSIS build script and a full-process-tree 200 MB RAM release gate.

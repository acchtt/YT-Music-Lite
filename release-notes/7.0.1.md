# YT Music Lite 7.0.1

This release continues the canonical `app-v7.0.x` line and replaces the WebView runtime with the low-memory native Windows client.

- Uses native WinForms with audio-only mpv playback instead of a persistent WebView2 player.
- Automatically syncs playlists and liked songs from the connected YouTube Music account.
- Loads playlist tracks on demand and virtualizes the sidebar for large libraries.
- Adds Discover Weekly, playlist management, a full playback bar, stable volume control, media keys, and a mini player.
- Repairs song artwork and replaces distorted hand-drawn controls with native Windows icons.
- Includes SHA-256-verified installer and portable update packages.
- Enforces a 140 MiB combined playback memory gate and an 80 MiB idle/post-stop gate.

The experimental `ytmlite-v7.1.x` and `ytmlite-v7.2.x` releases are superseded by this canonical channel.

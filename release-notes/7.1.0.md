# YT Music Lite 7.1.0

This release replaces the WebView2 build with the low-memory Windows-native client.

- Removes the continuously running Chromium/WebView2 process tree.
- Uses WinForms for the interface and `mpv` for audio-only playback.
- Adds previous, play/pause, next, stop, seek, volume, mute, shuffle, repeat-all, and repeat-one.
- Extends controls to the mini player, tray menu, keyboard shortcuts, and Windows media keys.
- Preserves the existing local library, playlists, history, and account settings.
- Ships as both an installer and a portable/in-app-update ZIP with SHA-256 checksums.
- Keeps the CI memory gate at 140 MiB combined for the client and player benchmark.

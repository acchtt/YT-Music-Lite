# YT Music Lite 7.1.1

This native Windows maintenance release stabilizes the playback sliders.

- Playback polling no longer overwrites volume or seek positions while a slider is being dragged.
- The selected volume is now authoritative, preventing delayed player snapshots from restoring an older value after release.
- Losing mouse capture commits the current slider value cleanly instead of leaving the control in a dragging state.
- The fix applies to both the main player and mini player.

# YT Music Lite 7.1.2

This release restores song covers and sharpens the native Windows interface.

- Reads both single-thumbnail and thumbnail-array metadata returned by YouTube searches and account sync.
- Repairs missing artwork URLs in existing library, history, and playlist records.
- Discards corrupt cache entries and redownloads them automatically.
- Center-crops YouTube artwork instead of stretching widescreen thumbnails into squares.
- Redraws settings, heart, volume, shuffle, and repeat glyphs for clear small-size rendering.
- Retains the native WinForms client, audio-only mpv playback, and the 140 MiB combined memory gate.

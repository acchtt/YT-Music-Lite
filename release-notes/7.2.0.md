# YT Music Lite 7.2.0

This release adds first-class playlists and lightweight personalized discovery to the native Windows client.

- Adds dedicated Playlists and Discover navigation pages.
- Supports local playlist creation, renaming, deletion, song management, and a native playlist-card overview.
- Imports and refreshes public or authenticated YouTube playlists by URL.
- Syncs authenticated liked songs into a visible Liked Music playlist as well as the saved-song library.
- Builds a Discover Weekly mix from recent plays and saved artists.
- Caches recommendations for seven days and limits refreshes to two small sequential searches.
- Retains native WinForms, audio-only mpv playback, bounded artwork caching, and the 140 MiB combined memory gate.

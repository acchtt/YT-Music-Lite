# YT Music Lite 7.2.1

- Automatically discovers playlists from the connected YouTube Music account.
- Refreshes the account library in the background at launch, with a six-hour throttle.
- Caches playlist names, artwork, and counts; tracks load only when a playlist is opened.
- Preserves cached library data when a partial YouTube sync fails.
- Replaces hand-drawn action and transport icons with native Windows Segoe MDL2 glyphs.
- Fixes the oversized heart button and shows a filled heart for saved songs.
- Retains native audio-only playback and the 140 MiB combined memory release gate.
